# Headless WordPress Blog

A simple blog built with React, TypeScript and Vite, using WordPress as a headless CMS to manage and display blog posts.

## Getting Started

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and add your WordPress site URL:

```env
VITE_WORDPRESS_URL=https://your-wordpress-site.com
```

Start the development server:

```bash
npm run dev
```
